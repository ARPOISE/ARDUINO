# ARpoise - ARDUINO
ARDUINO sketches for enhancing the user experience of ARpoise.
### DualCapacitiveFoil
Reading the inputs from two capacity foils. [DualCapacitiveFoil](https://github.com/ARPOISE/ARDUINO/tree/main/DualCapacitiveFoil).
### FollowTheHand
Reading the inputs from four ultrasonic sensors and animating a unity project.  [FollowTheHand](https://github.com/ARPOISE/ARDUINO/tree/main/FollowTheHand).
### MeasureDistance
Reading the inputs from two HC-SR04 ultrasonic sensors.  [MeasureDistance](https://github.com/ARPOISE/ARDUINO/tree/main/MeasureDistance).
### DualPirSensor
Reading the inputs from two HW-416 passive infrared sensors.  [DualPirSensor](https://github.com/ARPOISE/ARDUINO/tree/main/DualPirSensor).
### PiezoPitchDelay
Using two potentiometers driving pitch and delay of a piezo.  [PiezoPitchDelay](https://github.com/ARPOISE/ARDUINO/tree/main/PiezoPitchDelay).
